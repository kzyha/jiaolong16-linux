# EC 寄存器实测地图

机型：MECHREVO 蛟龙 16 2022（MRID6，宝龙达 BLD/Bitland 模具）
EC：ITE IT5570E，ACPI 端口 0x62/0x66，固件版本串 `AEC616864`（@0xB0）
访问方式：`modprobe ec_sys write_support=1` → `/sys/kernel/debug/ec/ec0/io`（256 字节，即 DSDT 中 ECF2 = SystemMemory 0xFE800400 的同一窗口）

| 偏移 | DSDT 名称 | 含义 | 读 | 写 | 备注 |
|------|-----------|------|----|----|------|
| 0x18–0x1B, 0x1E | TSR1-4,7-9 | 板载温度传感器 | ✅ | — | |
| 0x1C | TSR5 | **CPU 温度** | ✅ | — | 对 k10temp |
| 0x1D | TSR6 | **GPU 温度** | ✅ | — | 对 amdgpu edge |
| 0x20 bit3 | FNHK | Fn 键锁定 | ✅ | ✅ | |
| 0x25 bit0 | TOCP | 触控板锁定 | ✅ | ✅ | = Fn+F5，EC 实时响应 |
| 0x9A | KBNL | 键盘背光档位 | ✅ | ❌镜像 | 0/1/2/3 = 灭/33/66/100%，唯一控制途径 Fn+F9 |
| 0x9B–0x9E | F1HI/F1LO/F2HI/F2LO | 双风扇转速 | ✅ | — | 大端 16 位直读 RPM，压测 1970→4170 验证 |

## 验证方法论

- **转速度/温度**：压测（stress-ng + hashcat）期间 2 秒间隔连续 dump，与时序对齐
- **模式/颜色**：以「指示灯颜色」「肉眼可见变化」为最终验收——EC RAM 回读成功 ≠ 硬件生效（本项目中 KBNL/BPWM 镜像曾造成误判）
- **三色模式灯**：Fn+F10 切换时同步采样 + 用户肉眼报告颜色，三轮实验交叉锁定 0/1/2 映射

## 重要陷阱记录

1. **寄存器错位**：DSDT 字段表相邻 `Offset()` 指令容易数错一格——本项目曾把 LEDM 记成 0xE9（实际 0xE8），导致颜色写错位置、"灯死"乌龙（实为颜色被写成黑色）
2. **重启复位**：软重启会复位 EC RAM（模式回 0、颜色清空），但 LED 控制器内部状态可能残留
3. **EC 断电重置**：关机 → 拔电源 → 长按电源键 30 秒，可清除一切异常状态（救砖手段）
4. **内核模块可见性**：本机内核对普通用户的 `/proc/modules` 有过滤，`lsmod` 看不到 ec_sys 不代表未加载，以 root 查 `/sys/kernel/debug/ec/` 为准
