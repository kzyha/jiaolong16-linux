# 研究日志

## 第一阶段：现状盘点
- 确认机型/双 GPU/混合输出拓扑；发现无 platform_profile、无风扇 hwmon、无 LED 接口
- 社区方案逐一排查：nbfc 同方配置不匹配、TongFangRGB 协议无响应、ITE 0xCC 逐键协议不响应——后由模具归属修正解释：宝龙达底盘，同方生态全不适用

## 第二阶段：EC 逆向
- ec_sys 只读 dump + 压测时序采样：定位风扇转速 0x9B-9E、温度 0x18-1E
- 按键-采样对齐实验（Fn+F10 三轮颜色实验）：锁定性能模式 0xE4 的 0/1/2 映射
- 官方握手发现：TFLG=0x55 → ITSM 写入生效
- A 面 Logo 灯 FWDE（低有效）实测开关
- 键盘灯颜色控制：经历「寄存器错位一格」乌龙（颜色写错位置→"灯死"→EC 断电重置救回），最终定位 LEDM=0xE8 + RGB=0xE9-EB，模式 2 下实时生效

## 第三阶段：Windows 控制中心逆向
- innoextract + dnfile/dncil 完整反汇编 .NET IL
- WMI_METHOD_DEMO 测试桩给出全量功能号表
- 证实：亮度控制固件层不存在、风扇无写入通道
- 逆向出 MUX(func 9)/FnLock(11)/触控板锁(12) 命令，全部在本机固件 AML 中有对应 case → 实现并加入插件

## 第四阶段：DMS 插件开发
- DankMaterialShell 插件体系（plugin.json + PluginComponent + PopoutComponent）
- 迭代：状态显示 → 模式切换 → Logo 灯 → Fn/触控板锁 → MUX → 颜色选择器 → 功耗卡片 + 独显开关 + 双电源策略
- 踩坑：/tmp tmpfs 重启即清（源码母本移 ~/bin）；sudo 白名单仅限助手脚本路径；ec_sys 装卸竞态（改为常驻）

## 第五阶段：独显按需屏蔽
- v1 部署即翻车（黑名单无效 + 时序竞争 + niri 无回退）→ snapper 快照救回
- 日志破案 → v2 修正（mhwd 加载表 + Before=greetd + 占用保护）部署成功
- 深挖内核边界：带占用热拔死锁、半死状态毒化、关机阻断——全部实测记录
- 最终形态：双电源策略（插电自动开 / 拔电 RTD3 / 电池开机物理屏蔽）

## 第六阶段：BIOS 隐藏功能（只读）
- Windows 分区取固件 → 全量解包 → IFR 提取
- 发现完整 Advanced 菜单树 + AMD 超频变量表（AodSetup 偏移全拿到）
- SREP 运行时解锁机制解密（蛟龙 16Pro 社区包逐字节分析）
